# Skill: UI Design Craft & Commercial Visual Systems

Governs visual aesthetics, component consistency, design token architecture, and user experience standards across Exo Advance digital products.

## 1. Visual Freeze & Design System Fidelity
- **Strict Visual Coherence:** When maintaining or expanding an existing application, clone established design tokens (color palette, spacing scale, border radii, shadow elevation, and typography).
- **Signature Design Language:** Honor project-specific visual signatures (e.g., Tailwind `rounded-[32px]`, pill badges, subtle borders `border-slate-800/60`, and high-contrast dark/light accents).
- **Zero Style Fragmentation:** Prohibit introducing ad-hoc inline styles, conflicting CSS-in-JS libraries, or unverified Tailwind utility overrides.

## 2. Accessibility & Interaction Ergonomics (WCAG 2.1 AA)
- **High-Fidelity Contrast Ratios:** Maintain minimum 4.5:1 contrast for normal text and 3:1 for large text and interactive components.
- **Touch Target Ergonomics:** Enforce a minimum interactive touch target area of 44x44px for buttons, toggles, and navigation elements on mobile viewports.
- **Focus Indicators & Keyboard Nav:** Ensure visible, high-contrast focus rings (`focus-visible:ring-2`) and logical tab sequence across all interactive controls.

## 3. Responsive Fluid Layouts
- **Mobile-First & Commercial-Grade Desktop:** Design adaptive layouts with fluid container queries and standard breakpoints (`sm`, `md`, `lg`, `xl`, `2xl`).
- **Typographic Rhythm & Hierarchy:** Maintain strict vertical rhythm with proportional line-heights and font-weight differentiation (e.g., `font-black` headers, `font-medium` metadata).
- **Subtle Micro-Interactions:** Enhance UX with smooth transition states (`transition-all duration-200 ease-in-out`), hover elevations, and active press states.
